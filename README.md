# cocoa-skills

这是一个用于统一管理个人技能资产的仓库，目标是把可复用的技能定义、命令入口和安装脚本集中维护，便于后续持续迭代、跨设备同步与项目落地。

> 当前仓库是**技能资产管理仓库**，不是 Claude Code、OpenCode 或具体项目的运行时目录。

## 仓库定位

这个仓库主要解决三类问题：

- 统一维护自有技能与第三方技能
- 为 Claude Code 等工具提供稳定的命令入口
- 为后续全局安装、本地安装、迁移同步预留脚本能力

## 当前目录结构

```text
.
├── commands/
├── scripts/
└── skills/
    ├── external/
    └── own/
```

### 目录职责

#### `skills/own/`
用于存放自己维护的技能定义。每个技能单独一个目录，目录内以 `SKILL.md` 作为核心定义文件。

当前第一批技能：

- `review-pr`
- `write-tests`
- `summarize-diff`

#### `skills/external/`
用于存放引入仓库统一管理的第三方技能。

当前阶段约定：

- 第三方技能先入仓库，再进入安装流程
- 引入后尽量保留来源信息与必要说明
- 是否做本地改造、包装命令或二次适配，后续按实际使用情况补充

#### `commands/`
用于存放 Claude Code 命令入口文件。

这里的文件保持轻量，只负责把命令调用映射到对应技能，不在命令文件中重复维护整套技能逻辑，避免后续出现多处定义不一致的问题。

#### `scripts/`
用于存放安装、同步、迁移相关脚本。

第一阶段先建立职责清晰的最小骨架，后续再补充：

- 参数设计
- 复制策略
- 目标路径约定
- 覆盖与冲突处理
- 跨设备迁移流程

## 第一批技能说明

### `review-pr`
用于帮助快速审阅 Pull Request，聚焦变更摘要、风险点、潜在问题与建议行动。

### `write-tests`
用于围绕已有实现补充测试方案，优先覆盖核心路径、边界条件和回归风险。

### `summarize-diff`
用于对代码 diff 进行结构化总结，帮助快速理解本次改动的意图、范围与影响面。

## Claude Code 命令入口约定

命令文件与技能名称保持一致：

- `commands/review-pr.md`
- `commands/write-tests.md`
- `commands/summarize-diff.md`

这样做的目的：

- 降低记忆成本
- 便于后续自动安装与映射
- 保持技能目录与命令目录的一致性

## 安装与迁移思路

当前阶段先提供脚本骨架，后续逐步细化实现。预留的安装方向包括：

- `scripts/install-claude-global.sh`：安装到 Claude Code 全局目录
- `scripts/install-opencode-global.sh`：安装到 OpenCode 全局目录
- `scripts/install-project-local.sh`：安装到某个项目本地目录

后续脚本会重点解决这些问题：

1. 技能与命令文件如何复制到目标目录
2. 自有技能与第三方技能如何区分处理
3. 是否支持覆盖、跳过或备份已有文件
4. 如何在新设备上快速恢复完整技能环境
